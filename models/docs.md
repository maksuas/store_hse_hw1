# Аналитическое хранилище интернет-магазина

Проект предназначен для анализа заказов, платежей, клиентов и товаров интернет-магазина.

## Архитектура

- RAW - исходные данные из PostgreSQL.
- STAGING - подготовка исходных таблиц.
- INTERMEDIATE - соединение данных и сложная бизнес-логика.
- MARTS - готовые фактовые таблицы и измерения.

## Фактовые таблицы

- fct_orders - информация о заказах.
- fct_order_items - информация о товарных позициях.

## Измерения

- dim_customers - клиенты и история их покупок.
- dim_products - товары и иерархия категорий.
- dim_dates - календарное измерение.
